# Multi-Agent LLM Architectures for Interactive Storytelling and Game-Mastering (state as of Oct 2026)

Scope note: this file covers (1) academic GM/drama-manager systems, (2) world-state and memory, (3) consequence prediction/simulation, (4) player-intent handling, (5) narrative-to-media prompt generation, (6) orchestration engineering, (7) evaluation and failure modes. Every finding carries an inline source. Where a primary paper could only be read as an abstract, that is stated.

## KQ1. LLM game master / drama manager research: architectures and findings

### Takeaway
The field has converged on a "narrator + background state-keeper (+ validator)" split: a player-facing Narrator agent, an Archivist/Scribe that writes structured JSON world state in the background, and (in newer systems) an Examiner/Navigator that validates actions against an authored narrative graph. Controlled studies (N=12 each) show the multi-agent version beats a single-prompt GM on coherence, immersion and satisfaction, and that grounding redirection "in-world" beats hard denial; but long-horizon benchmarks show even frontier single models break facts in 40-68% of runs.

### Cited Findings
- **ChatRPG v2 (Static vs Agentic GM, 2025, Aalborg)**: v1 was one GPT-4 call per turn with three system prompts (Do/Say/Attack), JSON output, full history resent every turn; v2 is two ReAct agents: a *Narrator* (inputs: memory summary/history + player input; tools WoundCharacter, HealCharacter, Battle) and a background *Archivist* (inputs: JSON descriptions of all characters/environments + player input + narrator output; tools UpdateCharacter, UpdateEnvironment) that persists world state via Entity Framework. Within-subjects study N=12: v2 significantly better on ease of control (2.08→2.81, p=.012), goals/rules (1.35→2.39, p=.018), curiosity, mastery (0.68→2.33, p=.004), immersion (1.64→2.42, p=.034), interesting story (1.17→2.33, p=.019), coherent story (1.00→2.25, p=.040), satisfaction (1.08→2.17, p=.047). Failure modes: v1 combat produced nonsensical outcomes (characters tripping when no target identified), enemy counts/items drifted, quality degraded as context filled; v2 was highly prompt-sensitive (small wording changes altered Battle-tool invocation counts); OpenAI content filters interrupted violent combat. The authors split Narrator/Archivist specifically because a single agent that had to finish state updates before narrating was too slow. — [arXiv 2502.19519](https://arxiv.org/html/2502.19519v2)
- **ChatRPG v3 / SENNA (2025 Aalborg thesis "Narrative Adherence in LLM-driven Games")**: five agents — *Scribe* (invoked once; converts an adventure module into a Narrative Graph with AddNode etc.), *Examiner* (first agent per turn; returns Allowed / Conditionally Allowed / Disallowed with a grounded explanation, using the graph + campaign summary + a SearchScenario RAG tool over the module), *Navigator* (only runs on positive verdict; UpdateGraph tool checks edge conditions and marks nodes Completed/Ongoing, emits a change summary), *Narrator* (consumes verdict + graph summary; denies locked content "through immersive in-world cues"), *Archivist* (background memory; parses Narrator output for new/changed entities). N=12 study on "A Most Potent Brew": experience judged consistent, immersive, "comparable to a one-shot TTRPG"; the system "deviated from the module without breaking story logic". — [AAU thesis PDF](https://projekter.aau.dk/projekter/files/784680954/Narrative_Adherence_in_LLM_driven_Games.pdf)
- **NCP-Bench ("Can LLM Agents Stick to the Script?", 2026)**: 100 environments from movie synopses; each has a fact ledger, reference plot trajectory and *commitments* (invariants, ordering rules, achievement goals); an LLM auditor (Gemini-2.5-Flash) flags fact conflicts, commitment conflicts and player-input conflicts per turn. Results: GPT-5.2 best survival, 42% at 20 turns, avg 32.9 turns; fact conflicts are the dominant failure (40% GPT-5.2 to 68% Qwen3-235B); Kimi-K2.5 terminates at 2.88 turns avg; only 3.5% of runs reach 100 turns. Adding hierarchical working memory (HiAgent on GPT-4o-mini) cut commitment conflicts 26%→4% but raised player-input conflicts 13%→38% and fully-successful runs fell 2→0. A human narrator hit all 13 trajectory nodes and 7/12 commitments; most LLMs failed within five turns. Conclusion: "high linguistic quality does not guarantee commitment preservation"; explicit memory helps commitments but erodes fidelity to local player intent. — [arXiv 2608.08160](https://arxiv.org/html/2608.08160)
- **Structured Knowledge Tree detective game (Rahmati & Zhao, Sep 2026)**: tri-agent pipeline over a JSON knowledge tree whose nodes carry {ID, Fact, Revealed, Source (detective/suspect), Is Truth, Prerequisites[], Contradicts With[], Children[]}. *Analysis LLM* picks the single permissible unrevealed node whose parent is revealed; *Dialogue LLM* generates the suspect's line strictly from that node; *Detection LLM* verifies the fact was actually conveyed before the game flips the node to revealed and unlocks children. Unreal Engine 4 client calls the pipeline by API. User study (two 20-min sessions, SKT vs LLM-only, order randomized; logs hand-analyzed because players can't self-report hallucinations): critical hallucinations reduced 64.78%, premature disclosure eliminated entirely; trade-off is usability friction around forced reveals. — [arXiv 2609.23043](https://arxiv.org/abs/2609.23043)
- **Player-Driven Emergence (Microsoft Research, IEEE CoG 2024)**: fixed-premise text mystery with GPT-4 NPCs; 28 players; GPT-4 converted logs into narrative node-graphs; players discovered emergent nodes not in the authored narrative, most from "discovery/exploration" player types; the authors frame these as implicit designer feedback and note that "without human intervention, LLMs tend to repeat patterns". Part of MSR's "Emergence" project (players+creators+AI co-evolve games). — [arXiv 2404.17027](https://arxiv.org/pdf/2404.17027); [MSR project](https://www.microsoft.com/en-us/research/project/emergence/)
- **CALYPSO (AIIDE 2023)**: not an autonomous GM but three LLM interfaces assisting a human DM (encounter summarization, brainstorming, in-play focused assistance); 71 D&D players; DMs used output either as rough ideas or as near-read-aloud prose; LLMs "present thematic commonsense when prompted". — [arXiv 2308.07540](https://arxiv.org/pdf/2308.07540)
- **"Thirteen Hours… Labyrinth" (Wordplay@ACL 2024)**: AI GM with 14 functions (activate_test d6 roll with advantage/disadvantage; activate/terminate_action_scene; create_npc, add_object, use_environment; add/remove_trait, add/remove_flaw, add/remove_item, use_item; use_random_table). Scene state = chapter, scene summary, NPCs, success/failure conditions, intended flow, objects, random tables, consequences, action flag; player state = name, kin, goal, traits, flaws, inventory. Human eval (7 raters, 1-5): all-functions config best on consistency 4.39, reliability 3.95, interest 3.77 vs no-functions 3.42/3.36/2.80; letting GPT-4 free-write state updates (FG-gen) scored 0.267 on 30 state-update unit tests vs 0.461 for function-based updates. — [arXiv 2409.06949](https://arxiv.org/html/2409.06949v1)
- **Generative Agents (Park et al. 2023)**: memory stream of natural-language records; retrieval score = min-max-normalized recency (exponential decay 0.995 per game hour since last access) + importance (LLM-rated 1-10 at creation) + relevance (embedding cosine), equal weights; reflection triggers when summed importance of recent events exceeds 150 (≈2-3×/day): query 100 most recent memories → 3 salient questions → 5 insights each with citations; planning is hierarchical (5-8 daily chunks → hourly → 5-15 min). Ablation (TrueSkill, 100 raters): full 29.89 > no-reflection 26.88 > observation-only 25.64 > crowdworker-authored 22.95 > no-memory 21.21; all pairwise diffs p<.001 except human vs fully-ablated. — [arXiv 2304.03442](https://arxiv.org/html/2304.03442v2)
- **Humanoid Agents (EMNLP 2023 demo)**: adds a "System 1" layer (basic needs fullness/fun/health/social/energy, emotions, relationship closeness) to Generative Agents; loop = init → plan day → act → evaluate effect on needs/emotions → revise plan; Unity WebGL front end. — [arXiv 2310.05418](https://arxiv.org/pdf/2310.05418); [GitHub](https://github.com/HumanoidAgents/HumanoidAgents)
- **StoryVerse (FDG 2024, Autodesk)**: author writes "abstract acts"; an *Act Director* instantiates concrete acts against the current world; concrete acts play out through character simulation, feeding back into later acts; example: a character's death removed cast for later acts. — [arXiv 2405.13042](https://arxiv.org/pdf/2405.13042)
- **Drama Llama / Dramamancer (Midjourney, 2025-26)**: storylets with natural-language *conditions* and *outcomes*; two LLM modules per turn — *interpretation* (which conditions are now satisfied) and *instantiation* (next line, with a boolean `pause` flag deciding when to elicit player input; only NPC lines generated; satisfied outcomes are listed and "incorporated organically"). Story schema = style, characters (first = player), scenes (setting, verbatim opening line, events), events = storylets that can end/transition scenes. 6-author preliminary study found coherent narratives. — [Drama Llama arXiv 2501.09099](https://arxiv.org/abs/2501.09099); [Dramamancer design techniques arXiv 2601.18785](https://www.arxiv.org/pdf/2601.18785)
- **Unbounded (Google/UNC, ICLR 2025)**: a single distilled Gemma-2B "world simulation LLM" (trained on 5k GPT-4o-generated user/simulator sessions of 5 rounds, 6.5k steps on 4×A100) outputs per turn character actions/states, narrative, and image descriptions while tracking hunger/energy/fun/hygiene; ~1 s per scene vs ~5 s for a 7B model; GPT-4-judged quality 6.22 (base) → 7.44 (distilled), claimed comparable to GPT-4o. Image side: SDXL + DreamBooth LoRA (rank 16) + LCM LoRA + a dynamic regional IP-Adapter that masks character vs environment conditioning (top 60% of cross-attention) and drops the environment adapter from down-blocks. Beat StoryDiffusion on CLIP-IC 0.676 vs 0.629, DreamSim-C 0.488 vs 0.545. — [arXiv 2410.18975](https://arxiv.org/html/2410.18975v1)
- **CoSER (ICML 2025)**: 17,966 characters from 771 books; "given-circumstance acting" where one model sequentially plays each character in a scene; CoSER-70B (LLaMA-3.1) matches/surpasses GPT-4o on role-play benchmarks. — [ICML proceedings](https://proceedings.mlr.press/v267/wang25dk.html)
- **Agent Hospital**: full treatment cycle with LLM patients/nurses/doctors; doctor agents self-improve from ~10k simulated cases to 93.06% on a MedQA respiratory subset (relevance here: evidence that agent societies can accumulate experience without labels). — [arXiv 2405.02957](https://arxiv.org/pdf/2405.02957v1)
- **Showrunner / SHOW-1 (Fable, 2023)**: Sims-like multi-agent simulation (needs, relationships, affordance providers) logs events into "Reveries" (per-event and per-day reflections); user supplies synopsis + major events for 14 scenes of a ~22-min episode; prompt chain: scene title → dialogue → cloned-voice clips generated one-ahead in a buffer → staging/AI camera; ~1 min per scene; listed risks: "slot-machine effect", "10,000 bowls of oatmeal" repetitiveness, blank-page problem, inability to judge reversals/foreshadowing inside a chain. — [Fable SHOW-1 page](https://fablestudio.github.io/showrunner-agents/)
- **Façade (Mateas & Stern)**: beat-based drama manager sequencing ~ beats by tension preconditions along an Aristotelian arc; NLU rules mapped free text into ~30 dialog moves; authors said they reached ~30% of their vision. The 2026 "AI Native Games" survey argues Façade's lasting contribution is the design proposition that social language is the primary gameplay material, not technical continuity with LLM systems. — [AIIDE Façade paper](https://ojs.aaai.org/index.php/AIIDE/article/view/18722); [AI Native Games survey arXiv 2607.00527](https://arxiv.org/pdf/2607.00527)
- **Hidden Door (production)**: narrative engine built from pre-generated and sometimes hand-written "trope" fragments (e.g., bar brawl → found weapon → bottle) that chain; items/NPCs generated as the world is built; proprietary language and art models; follows licensed-world rules (who can die, nature of magic). — [GamesBeat](https://gamesbeat.com/hidden-door-reveals-its-ai-powered-narrative-game-building-platform/); [PC Gamer](https://pcgamer.com/hidden-door-ai-game-narrative-rpg). Independent design review (Aug 2025 public release): state is a set of "cards" (characters, locations, objects, plot directions); each beat = short passage + 3 choices + custom-type; typed input is *not* resolved directly but regenerates the choice menu (a moderation layer); d20 rolls in the prompt but the player "almost always succeeds"; story is "ungrounded" (no hidden truth beyond what's been read; objects acquire properties only when mentioned); continuity errors (car→road→car), character traits over-indexed, objectives appearing and auto-completing, choices with no consequence. — [Ian Bicking review](https://ianbicking.org/blog/2025/08/hidden-door-design-review-llm-driven-game)
- **Latitude Wayfarer (AI Dungeon)**: 12B/70B models fine-tuned because "players kept complaining that modern models are too nice, never letting them fail or die"; stage 2 SFT on 50/50 synthetic 8k-context text adventures (narrator model vs player model kept unaware of each other's reasoning; runs end at 8k tokens or on PC death) + roleplay; described as "pessimistic sentiment, frequent failure, absence of plot armor". — [HF model card](https://huggingface.co/LatitudeGames/Wayfarer-12B)

### Inferences
- The consistent winning decomposition across ChatRPG v2/v3, SKT, Labyrinth and Hidden Door is: (a) one cheap deterministic/structured source of truth (JSON entities, narrative graph, knowledge tree, function-updated state), (b) a Narrator that only renders what it is handed, (c) a background writer that updates state after the narration so the player-facing path is not blocked. This maps directly onto the proposed Writer / Memory / Interact split.
- The NCP-Bench HiAgent result is a warning for the Memory agent design: aggressive memory/commitment enforcement can make the system ignore or rewrite the player's action; a validator must return "conditionally allowed" plus a reason rather than silently overriding.
- Unbounded shows that a distilled 2B model can run the per-turn simulation at ~1 s if the output schema is narrow and the training data is synthesized by a strong model, which supports a "small/fast model for the inner loop, big model for authoring/reflection" split.

### Gaps
- I found no public source for "GPT-RPG", "Weave", or "Fate / Director agents" as named systems; they may be unpublished or differently named. No reliable source for GENEVA's metrics was retrieved.
- Hidden Door's internal architecture beyond tropes/cards is undocumented; no GDC 2025/2026 talk by Hidden Door was found.
- Dramatron's internal pipeline and failure modes could only be read as an abstract (15 industry professionals co-wrote; critical reflections reported). — [arXiv 2209.14958](https://arxiv.org/abs/2209.14958)

## KQ2. World-state and memory representation for consistent consequences

### Takeaway
Evidence favors a three-layer representation: an explicit structured state (JSON/graph/code) as the ground truth, a natural-language episodic log with importance/recency/relevance retrieval plus periodic reflection, and an authored constraint layer (narrative graph / knowledge tree / commitments). Free-text-only state is the common source of continuity failures; structured-but-stale state is the source of "player ignored" failures.

### Cited Findings
- Text World Models survey (2026) proposes a two-axis taxonomy; on the representation axis: (1) natural language "weakly constrains consistency, completeness, and executability"; (2) structured (JSON, key-value, knowledge graphs, accessibility trees, PDDL predicates) "exposes entities, relations, preconditions, and effects in a form that is easier to track and verify"; (3) executable code "yields stronger reproducibility and constraint enforcement". It cites Li et al. 2026b: full-state prediction reaches ~99% single-step accuracy on *structured* environments such as ALFWorld, versus far lower on open text games. "When to use which": if transitions are fixed and expressible in code (game rules, tool APIs), code-as-world-model is "the natural fit"; open-ended commonsense dynamics require LLM-as-WM. Recurring failure "hallucination drift" is mitigated by re-grounding in structured state (e.g., AWM backs each synthesized environment with a SQLite DB) or constraining output space. — [arXiv 2606.09032](https://arxiv.org/pdf/2606.09032)
- ChatRPG v1 kept everything as one long text + full history and saw item/enemy drift and degradation as the context filled; v2 moved to JSON character/environment records persisted in a database and updated by a background agent. — [arXiv 2502.19519](https://arxiv.org/html/2502.19519v2)
- Labyrinth GM: state as Python objects flattened into every prompt; free-form LLM state editing scored 0.267 vs 0.461 for function-mediated updates on unit tests. — [arXiv 2409.06949](https://arxiv.org/html/2409.06949v1)
- SKT detective game: authored JSON tree with prerequisites, contradiction links and truth flags gave 64.78% fewer critical hallucinations and zero premature reveals. — [arXiv 2609.23043](https://arxiv.org/abs/2609.23043)
- NCP-Bench: fact-ledger + commitments is the evaluation substrate; hierarchical working memory (HiAgent) cut commitment conflicts 26%→4% but raised player-input conflicts 13%→38%. — [arXiv 2608.08160](https://arxiv.org/html/2608.08160)
- Generative Agents memory: natural-language stream; retrieval = recency(0.995^hours) + importance(1-10) + relevance(cosine), reflections stored as memories citing evidence, forming trees; removing reflection dropped believability 29.89→26.88 and removing memory entirely 21.21. — [arXiv 2304.03442](https://arxiv.org/html/2304.03442v2)
- Hidden Door review: the author's central recommendation is "maintain a simple, objective state (player location, relationships, hidden facts) separate from the prose", "outline before prose", "enforce consistency in code (attributes, pronouns)". — [Ian Bicking](https://ianbicking.org/blog/2025/08/hidden-door-design-review-llm-driven-game)
- AI Native Games survey: "memory instability" — a locally valid generated action may fail to persist; forgetting decrees/relationships/resource changes breaks "state persistence and causal coherence"; proposes generate-and-verify (does the object exist? can the player reach the location? does the outcome contradict prior state?). — [arXiv 2607.00527](https://arxiv.org/pdf/2607.00527)
- General agent-memory systems (vendor-reported benchmarks, disputed): MemGPT = OS-style virtual context management, tiered main/external context, interrupts for control flow — [arXiv 2310.08560](https://arxiv.org/abs/2310.08560). Zep/Graphiti = temporally-aware knowledge graph combining conversational and structured data with historical relationships; DMR 94.8% vs MemGPT 93.4%; up to 18.5% LongMemEval gain and 90% latency reduction vs baselines — [arXiv 2501.13956](https://arxiv.org/abs/2501.13956). A-MEM = Zettelkasten-style notes with contextual descriptions/keywords/tags, LLM-created links, and "memory evolution" that rewrites older notes when new ones arrive — [arXiv 2502.12110](https://arxiv.org/abs/2502.12110). Mem0 vs Zep LoCoMo numbers conflict (Mem0 self-reports ~91-92%; Zep's configurations 62-83%; each disputes the other's methodology; Mem0 LongMemEval 93-94% vs Zep 71.2% per Mem0) — [Mem0 benchmarks](https://mem0.ai/blog/ai-memory-benchmarks); [Mem0 vs Zep](https://mem0.ai/blog/zep-vs-mem0-which-ai-memory-layer-should-you-choose). Letta (MemGPT successor) is Apache-2.0 — [comparison](https://blckalpaca.at/en/knowledge-base/ai-agents/ai-agent-frameworks-comparison.md).

### Inferences
- For the "if the player digs here, what's underground?" case, the SKT/Hidden Door contrast is instructive: an *ungrounded* world (properties materialize when mentioned) makes consequences arbitrary; a lazily-populated but *committed* world (generate once, write to state, reuse — the "Infinite Craft caching" principle in the AI Native Games survey) makes them stable.
- Importance-weighted reflection (Generative Agents) is the cheapest known way to produce "semantic memory" summaries that keep long sessions coherent; it should be run by the Memory agent off the critical path.
- Temporal KG memory (Graphiti) is the best fit for "what did NPC X believe at time T" queries, but the benchmark numbers are vendor-contested; treat them as unverified.

### Gaps
- No game-specific head-to-head of vector memory vs knowledge-graph memory vs structured JSON for *interactive fiction* was found; the memory-product benchmarks (LoCoMo/LongMemEval) are chat QA, not game state.
- HippoRAG was not retrieved in this pass.

## KQ3. Consequence prediction / simulation ("what happens if the player does X")

### Takeaway
LLMs are unreliable as pure simulators of environment dynamics (GPT-4 ~44% on environment-driven transitions vs ~76% on action-driven), so the recommended pattern is hybrid: deterministic code/rules for anything with closed-form semantics (dice, inventory, locks, damage), structured state-difference prediction by an LLM for open-ended commonsense effects, and verification before commit. Sycophancy (the model preserving the user's "face") is a documented bias that must be countered by taking success decisions away from the narrator.

### Cited Findings
- Wang et al. ACL 2024 (ByteSized32-State-Prediction): GPT-4 full-state accuracy on dynamic transitions 59.0% overall; action-driven 76.1% vs environment-driven 44.1% (LLM-written rules); no rules drops env-driven to 24.4%; predicting state *differences* helps static transitions (env static 61.9%→93.8%) but hurts dynamic ones (38.6%→22.2% with human rules); errors cluster on arithmetic (temperature), commonsense (aperture/focus) and scientific properties; when both transition types are predicted together GPT-4 focuses on action-driven changes and leaves env-driven ones unaltered; humans scored 0.80 vs GPT-4 0.49 on a hard subset. Conclusion: GPT-4 "is still an unreliable world simulator without further innovations". — [arXiv 2406.06485](https://arxiv.org/html/2406.06485v1)
- WorldCoder (NeurIPS 2024): agent writes a Python program as its world model from interactions, treating it as a hypothesis that must explain observations; more sample-efficient than deep RL and more compute-efficient than ReAct; transfers by editing code. — [NeurIPS](https://proceedings.neurips.cc/paper_files/paper/2024/hash/820c61a0cd419163ccbd2c33b268816e-Abstract.html)
- Text2World (ICLR-W 2025): PDDL world-model generation benchmark over hundreds of domains; RL-trained reasoning models do best but "even the best-performing model still demonstrates limited capabilities in world modeling". — [mlanthology](https://mlanthology.org/iclrw/2025/hu2025iclrw-text2world)
- Text World Models survey: code-as-WM "executes transitions deterministically, enabling formal verification, exact reproducibility, and a clean separation between the LLM's role (writing the code) and the world model's role (running it)"; prompt-based LLM simulators "suffer from hallucination and poor calibration"; delta prediction "reduces the output space and concentrates supervision on causally relevant information". — [arXiv 2606.09032](https://arxiv.org/pdf/2606.09032)
- STORY2GAME (2025): generates a story, populates a world, and writes action code from LLM-derived preconditions and effects for playable IF. — [search summary via arXiv listing](https://github.com/yingpengma/Awesome-Story-Generation)
- Sycophancy evidence: ELEPHANT benchmark — across 11 models, LLMs preserve the user's "face" 45 percentage points more than humans in advice queries; sycophancy interacts with recency bias (stronger when the user's position comes last — i.e., the player's just-typed action). — [arXiv 2505.13995](https://www.alphaxiv.org/abs/2505.13995.md)
- Practitioner pattern: an LLM narrator "will cheerfully let your level-1 fighter one-shot a dragon, because it has no concept of dice, hit points, or fairness"; fix = every mechanical decision in deterministic server code, "the model only ever narrates results it's handed". — [dev.to write-up](https://dev.to/pracode_2503/llms-as-dungeon-masters-can-ai-run-a-tabletop-game-without-cheating-425m)
- Hidden Door in practice: d20 in the prompt, but the reviewer observed the player "almost always succeeds" and that failures should "disrupt the world state, not just add flavor". — [Ian Bicking](https://ianbicking.org/blog/2025/08/hidden-door-design-review-llm-driven-game)
- Labyrinth GM: a dedicated `activate_test` d6 function with GM-set difficulty and trait/flaw advantage; the all-functions configuration scored highest on consistency and interest; a states-only config lacking dice scored higher on unit tests but "excessive state calls disrupted gameplay". — [arXiv 2409.06949](https://arxiv.org/html/2409.06949v1)
- Wayfarer: training the narrator against a *separate* player model that it cannot see, with runs ending on character death, is Latitude's method for producing a model that lets players fail. — [HF model card](https://huggingface.co/LatitudeGames/Wayfarer-12B)

### Inferences
- A Prediction agent should be asked for *state deltas* on a structured schema (what entities change, which properties), not free prose, and only for properties the rules engine does not own; arithmetic/physical properties should be computed in code because those are exactly where GPT-4-class models failed.
- "Fair and surprising" outcomes can be produced by sampling the outcome *before* narration (probability table or dice resolved in code, seeded per-branch so the Cache agent can pre-generate both success and failure branches), then handing the Writer the fixed result — this removes the narrator's opportunity to be sycophantic.
- For "what is underground here?", a lazily-materialized world generator (LLM proposes contents constrained by biome/lore schema → validator → written to state) matches the survey's generate-and-verify recommendation and the Infinite-Craft caching principle.

### Gaps
- No paper was found that measures *rate of unearned player success* in LLM GMs directly; the sycophancy link to "yes, and" improv is inference, not a measured result.
- No benchmark of LLM consequence prediction specifically for narrative (as opposed to text-game physics) was found.

## KQ4. Player-intent interpretation and "you can do anything" vs stakes

### Takeaway
The best-evidenced pipeline is: parse free text → structured intent → check against deterministic state/inventory → LLM judge only for fuzzy plausibility → return a verdict with an in-world reason. Players rate in-world consequences and NPC influence as far better than hard denial, and benchmarks list "blocking actions without causal justification" and "silently rewriting the player's action" as systematic failures.

### Cited Findings
- ChatRPG v3 Examiner verdicts: Allowed / Conditionally Allowed (success uncertain, failed attempts) / Disallowed (violates constraints, skips plot, inconsistent) each with a grounded explanation; six redirection strategies: Hard Denial ("The door does not budge", no justification), Offering Information (NPC warnings/environmental cues), Illusion of Choice (quantum ogre), NPC Influence (characters caution/appeal), Humor, In-World Consequences (allow the disruptive act, deliver logical fallout, e.g., robbing an NPC → blacklisted). Five expert GMs ranked them; study (N=12, PXI + ASAQ + interviews, each key scene replayed in four strategy versions): In-World Consequences most preferred, then NPC Influence, then More Information; Hard Denial consistently least appropriate; strategy choice significantly affected perceived appropriateness and narrative smoothness. Participants "generally accepted moments of narrative steering, especially when grounded in character or world logic". — [AAU thesis](https://projekter.aau.dk/projekter/files/784680954/Narrative_Adherence_in_LLM_driven_Games.pdf)
- Labyrinth GM reliability criterion explicitly includes rejecting actions the character cannot perform and rejecting use of items/traits/objects/NPCs/random tables that do not exist. — [arXiv 2409.06949](https://arxiv.org/html/2409.06949v1)
- NCP-Bench failure taxonomy includes "blocking player actions without adequate causal justification" (e.g., narrator halts a self-destruct and leaves an escape pod dormant with no explanation) and silently rewriting player actions; cooperative "natural" player inputs lengthened sessions (46.1 vs 22.2 turns) but did not fix commitment failures. — [arXiv 2608.08160](https://arxiv.org/html/2608.08160)
- AI Native Games survey: "generate-and-verify" — model proposes an action interpretation/event/outcome; game system checks object existence, reachability, contradiction; on failure, revise or ask the player; must decide "which rules must remain fixed" and where "semantic freedom" is granted. — [arXiv 2607.00527](https://arxiv.org/pdf/2607.00527)
- Hidden Door: typed input does not resolve directly — it regenerates the choice menu, and some inputs are rewritten into safer versions (a moderation/scoping layer); reviewer recommends limiting free-text "hacking" because it undermines pressure to write strong choices. — [Ian Bicking](https://ianbicking.org/blog/2025/08/hidden-door-design-review-llm-driven-game)
- Dramamancer: player input is only ever the player character's actions/dialogue; the LLM is told the player character's lines must come only from the player; a `pause` boolean decides when input is elicited; "responsiveness to the most recent player input regardless of whether it triggers an event" is a stated prompt requirement. — [arXiv 2601.18785](https://www.arxiv.org/pdf/2601.18785)
- Façade precedent: free text mapped by hand-written NLU rules into ~30 discourse acts before the drama manager reacts. — [AIIDE](https://ojs.aaai.org/index.php/AIIDE/article/view/18722)
- Cheap-model gate pattern: a hobby IF project runs a small model first to reject impossible/anachronistic/off-tone actions in character "before any expensive call is made". — [towardsdatascience write-up](https://towardsdatascience.com/how-i-built-an-llm-based-game-from-scratch-86ac55ec7a10/)
- Content filtering as a scope limit: ChatRPG noted OpenAI filters interrupting combat descriptions. — [arXiv 2502.19519](https://arxiv.org/html/2502.19519v2)

### Inferences
- The Interact agent should emit a typed intent object (actor, verb, target, instrument, manner) plus a feasibility verdict and a *reason*; the Writer should receive the verdict and reason so refusals are always narrated causally. "Conditionally allowed" should route to the dice/probability resolver rather than to the narrator.
- A "yes, but / no, because" policy is directly supported by the ChatRPG v3 data: prefer In-World Consequences (yes, and here is the fallout) and NPC Influence over Hard Denial.

### Gaps
- No academic treatment of voice-input intent parsing for LLM GMs was found; all studies used typed text.
- No published data on how often players attempt world-breaking actions in live products.

## KQ5. Prompt generation for image/video models with continuity

### Takeaway
Research pipelines (MovieAgent, FilmAgent, AniMaker, Unbounded) all use a hierarchical planner (script → scenes → shots) producing per-shot fields (characters, action/plot, shot type, camera movement, lighting, dialogue/subtitle) and a **character bank** (name, portrait reference images, voice samples) consumed by reference-conditioned generators; identity is held by reference images/LoRA plus attention-level consistency (StoryDiffusion consistent self-attention, regional IP-Adapter masking), and no method yet achieves perfect cross-clip consistency.

### Cited Findings
- MovieAgent (NUS Show Lab, 2025): Director agent splits synopsis into sub-scripts (narrative structure, character continuity); Scene Plan agent writes scenes (characters, plot, emotional tone, visual style, cinematography notes); Shot Plan agent writes shots (shot type, camera movement, lighting, VFX, subtitles); each stage uses a 5-step internal CoT (narrative analysis → key elements → boundary definition → cinematic/emotional enhancement → technical planning). Character bank = name + portrait images + audio samples, fed to StoryDiffusion / AutoStory / Magic-Me; video via CogVideoX, talking heads via Hallo2, audio via VALL-E X. Human scores (0-5): character consistency 4.04, script faithfulness 3.89, narrative coherence 3.49, physical law 3.42; multi-agent+CoT 3.82 vs single GPT-4o 3.55. — [arXiv 2503.07314](https://arxiv.org/html/2503.07314v1)
- FilmAgent (2025): LLM crew roles in a pre-built 3D space (idea → script → cinematography) with Critique-Correct-Verify and Debate-Judge collaboration; human eval 3.98/5, beating single-agent o1 while using GPT-4o. — [arXiv 2501.12909](https://arxiv.org/pdf/2501.12909)
- AniMaker (successor of Anim-Director): multi-agent animated storytelling with MCTS-driven clip selection; clip generation is the main time cost — a short still takes hours. — [HF papers](https://huggingface.co/papers/2506.10540)
- StoryDiffusion (NeurIPS 2024): training-free Consistent Self-Attention linking images in a batch for identity; Semantic Motion Predictor for video between keyframes; code targets SD1.5/SDXL-era models. — [arXiv 2405.01434](https://arxiv.org/html/2405.01434v1)
- Unbounded: environment adapter and character adapter blended by a dynamic cross-attention mask (top 60%), environment adapter removed from down-blocks; outperforms StoryDiffusion on character and environment consistency metrics; the LLM emits an image description per turn alongside the narrative. — [arXiv 2410.18975](https://arxiv.org/html/2410.18975v1)
- Gloria (CVPR 2026): "consistent character video generation via content anchors", >10-minute character videos with identity consistency across views (abstract only). — [arXiv 2603.29931](https://arxiv.org/abs/2603.29931)
- Showrunner: custom diffusion models trained offline on ~1,200 character images and 600 backgrounds; assets generated offline then upscaled; voices cloned in advance; clips generated one-ahead. — [Fable](https://fablestudio.github.io/showrunner-agents/)
- 2026 production practice (vendor sources, weigh accordingly): reference conditioning (one or more images/clips of the exact character) is the main lever; LoRA fine-tuning is slower but more faithful and reusable; recommended structure = locked multi-angle character sheet + saved style block + themed scene references attached to every generation; multi-frame storyboard tests still drift (jacket color changed by frame 4 of 8); "no AI model in mid-2026 achieves perfect character consistency across multiple video clips". — [Fora Soft](https://www.forasoft.com/learn/ai-for-video-engineering/articles-ai/character-scene-camera-consistency-production); [Genra](https://genra.ai/blog/ai-video-character-consistency-guide); [Neural4D comparison (vendor)](https://blog.neural4d.com/comparisons/best-ai-video-generator-for-consistent-characters/)

### Inferences
- The Prompt agent's output schema should mirror the MovieAgent shot record plus explicit references: {character_ids → reference image/LoRA ids, location_id → reference, style block (fixed), shot type, camera move, lighting, action beat, dialogue, duration}. Keeping the style block and character sheets immutable and attaching them to every request is the common denominator of every pipeline above.
- Because video generation is the dominant latency (hours for AniMaker shorts; one-ahead buffering in Showrunner), the Film agent must be pipelined and speculative (see KQ6); narrative beats should be designed so that a clip's first seconds are reusable across branches.

### Gaps
- No paper gives measured latency for *real-time* narrative→video within a game loop; all pipelines are offline.
- No primary source on how Showrunner's current (2025-26) product handles continuity beyond the 2023 paper.

## KQ6. Orchestration engineering: frameworks, latency, speculation, cost

### Takeaway
Mainstream frameworks are now MIT/Apache-licensed and converge on graph workflows + checkpointing + streaming + MCP; the game-relevant engineering patterns with evidence are (a) split critical path (narrator) from background writers, (b) distil a small model for the per-turn loop, (c) speculative execution of likely next actions with commit/rollback (≤50% theoretical latency bound, ~20% measured), (d) layered simulation with caching of generated facts, and (e) model-tiering because cost per player-hour spans roughly $0.1 to several dollars depending on model and context size.

### Cited Findings
- Frameworks and licenses (mostly from third-party comparisons; verify in repo): LangGraph MIT, StateGraph + checkpointer, 1.x GA (1.2.0 May 2026), ~26-32k stars; CrewAI MIT core + enterprise tier, v1.14.x (Apr 2026); OpenAI Agents SDK pre-1.0 (≥0.14, Apr 2026), lightweight tools+handoffs, license reported as MIT by one source and Apache/MIT by another; Letta (MemGPT) Apache-2.0, ~23k stars, maintenance signals conflicting. — [blckalpaca comparison](https://blckalpaca.at/en/knowledge-base/ai-agents/ai-agent-frameworks-comparison.md); [alicelabs 2026 comparison](https://alicelabs.ai/en/insights/open-source-ai-agent-frameworks-comparison-2026)
- Microsoft Agent Framework (successor to AutoGen and Semantic Kernel): MIT; Python and C#/.NET with Go in a separate repo; graph workflows with sequential, concurrent, handoff and group patterns; checkpointing, streaming, human-in-the-loop, time-travel debugging; migration guides from SK and AutoGen; AutoGen in maintenance mode since Oct 2025. One source says 1.0 GA on 3 Apr 2026, another still "public preview" — conflicting. — [GitHub](https://github.com/microsoft/agent-framework); [Atlan comparison](https://atlan.com/know/ai-agent/microsoft/microsoft-agent-framework-vs-other-agent-frameworks/); [is4.ai](https://is4.ai/blog/our-blog-1/semantic-kernel-microsoft-ai-framework-2026-291)
- Google ADK: GA April 2025; Python, TypeScript, Go, Java, Kotlin; hierarchical, GCP-native; a 2026 RCE CVE (CVE-2026-4810, CVSS 9.8) reported by a vendor blog, unverified. All major frameworks document MCP; several support A2A. — [Atlan ADK vs LangGraph vs AutoGen](https://atlan.com/know/ai-agent/ai-agent-applications/google-adk-vs-langgraph-vs-autogen/)
- Inworld Runtime: described by Inworld as a model-agnostic AI orchestration platform carrying over Studio features (knowledge retrieval, safety checks, long-term memory, voice) with "unified model access, tooling for experimentation, and telemetry/observability"; multi-agent "Director" for character-to-character conversation; TTS-1.5 advertised under 120 ms; docs require login so node/graph internals could not be read. — [Inworld UE docs](https://dev.docs.inworld.ai/unreal-engine/runtime/overview); [Contrary Research profile](https://research.contrary.com/report/inworld-ai)
- Speculative Actions (ICLR 2026): Actor issues real API call while cheap Speculators predict the next environment step (e.g., opponent's chess move) and pre-run downstream work; commit on match, roll back otherwise ("lossless"); implemented on TextArena; up to 55% next-action prediction accuracy and ~20% end-to-end speedup (chess: 54.7% accuracy; 3 parallel predictions → 19.5% average time saved over 30 steps); Proposition 1 bounds end-to-end reduction at 50%; cost grows "substantially slower" with confidence-based selective branch launching than with naive breadth scaling. — [arXiv 2510.04371 / Columbia PDF](https://www.cs.columbia.edu/~kkaffes/papers/speculative-actions-iclr26.pdf)
- Speculate with Memory (2026): a stateless speculator plateaus near ~28% latency reduction; adding structured memory of past trajectories lifts it above 50% on ALFWorld. — [arXiv 2607.12236](https://arxiv.org/pdf/2607.12236)
- Unbounded: distillation to Gemma-2B gave ~1 s/scene vs ~5 s for 7B, "5-10x over naive implementation". — [arXiv 2410.18975](https://arxiv.org/html/2410.18975v1)
- ChatRPG v2: moved state writing off the critical path into a background Archivist because waiting for state updates before narrating was too slow. — [arXiv 2502.19519](https://arxiv.org/html/2502.19519v2)
- Showrunner: ~1 min per scene generation; voice clips buffered one ahead; multi-step pipeline hidden from users to avoid the "slot machine" feel. — [Fable](https://fablestudio.github.io/showrunner-agents/)
- AI Native Games survey engineering guidance: avoid calling large models for every interaction; "frequent and low-risk behavior can be handled by local small models or traditional AI, while larger models are reserved for moments where semantic uncertainty matters"; cache generated results (Infinite Craft pattern) to turn generation into durable state; distillation, quantized local inference, speculative decoding, batching for multi-agent scenes; "layered simulation: lightweight routines for background behavior, foundation-model inference for interactions that matter"; typed turn-waiting "makes the loop feel less like play and more like waiting for a remote service"; business models split into local/BYOK for packaged titles vs subscriptions+credits for platforms; "token-based billing is not yet a mature business model, and inference cost may exceed players' willingness to pay". — [arXiv 2607.00527](https://arxiv.org/pdf/2607.00527)
- Cost data points (all vendor/anecdotal): one studio reported ~$3 per player-hour in early unoptimized playtests (i3D.net post); a worked example of 100 NPC interactions/hour × ~10k lore tokens ≈ 1M input tokens/player-hour (≈$3/h at $3/M, ≈$0.08/h at $0.075/M); Death by AI used ~1.2B tokens in its first month on GPT-3.5/4 + ElevenLabs and found it "not financially sustainable" before moving to Inworld; Inworld claims 50%+ price cuts and a customer 95% cost reduction; a third-party listing cites Inworld runtime overage at $0.016/min (~$0.96/h), unverified. — [TrackIt](https://trackit.io/connecting-npcs-to-llms-in-games); [Inworld case study](https://inworld.ai/blog/how-inworld-helped-the-ai-game-death-by-ai-with-20-million-players-reach-profitability); [Inworld price cut PR](https://www.morningstar.com/news/business-wire/20260610968386/inworld-cuts-prices-to-take-down-the-biggest-wall-in-consumer-ai-cost); [eesel pricing (third party)](https://www.eesel.ai/blog/inworld-ai-pricing)

### Inferences
- Event-driven design: ChatRPG v2/v3, SKT and Showrunner all effectively use a sequential critical path (validate → resolve → narrate → render) with asynchronous side-effects (state write, reflection, asset pre-generation); a pub/sub bus where the Narrator's output event fans out to Memory, Prompt/Film and Cache agents reproduces this.
- For the Cache agent, the Speculative Actions math applies directly: speculate on the top-k likely player intents (k chosen by predicted accuracy), pre-run Prediction→Writer→Prompt→Film for each, commit on match; expected gain is bounded by ~50% and realistically ~20-50% depending on how predictable the player is, with cost growing sub-linearly if branches are launched only above a confidence threshold. Memory-informed speculators (per-player habit models) raise hit rates.
- Model tiering per role suggested by the evidence: Interact/Examiner and Prediction deltas on small fast models (gated, structured outputs); Writer on a mid/large model; reflection/Scribe (one-time module→graph) on the largest model offline.

### Gaps
- No published end-to-end latency for a multi-agent narrative turn in production (Inworld, Hidden Door, Latitude) was found.
- No source combines branch pre-generation with video generation in a game loop; the speculative-actions numbers are from chess/e-commerce/web search.
- Framework star counts/versions are from third-party blogs and disagree; licenses for OpenAI Agents SDK conflict between sources.

## KQ7. Evaluation methods, user-study results, and failure modes

### Takeaway
Evaluation combines PXI/ASAQ-style player surveys and interviews (N≈12), LLM/human auditing of logs for fact and commitment conflicts, and author-side vs player-side variable sets; the two controlled comparisons available both favour multi-agent over single-prompt GMs, while benchmarks and field reviews converge on the same failure list: fact drift, forgotten state, over-accommodation, unjustified blocking, repetition/"oatmeal", trait over-indexing, prompt brittleness, and latency.

### Cited Findings
- Multi-agent vs single-prompt: ChatRPG v1→v2 N=12 within-subjects, 8-9 constructs significantly better for the agentic version (coherent story 1.00→2.25 p=.040; immersion p=.034). — [arXiv 2502.19519](https://arxiv.org/html/2502.19519v2). MovieAgent ablation: multi-agent+CoT 3.82 vs single GPT-4o 3.55 (human avg). — [arXiv 2503.07314](https://arxiv.org/html/2503.07314v1). FilmAgent multi-agent GPT-4o beat single-agent o1. — [arXiv 2501.12909](https://arxiv.org/pdf/2501.12909). Labyrinth: functions vs none, consistency 4.39 vs 3.42. — [arXiv 2409.06949](https://arxiv.org/html/2409.06949v1). SKT vs LLM-only: −64.78% critical hallucinations. — [arXiv 2609.23043](https://arxiv.org/abs/2609.23043)
- Metrics in use: NCP-Bench survival rate, average turns, trajectory progress, % commitments satisfied, fact/commitment/player-input conflict rates, with auditor sensitivity checks and 100 human-reviewed cases. — [arXiv 2608.08160](https://arxiv.org/html/2608.08160). Dramamancer proposes author-side (style adherence, character distinctiveness, scene awareness, event-detection accuracy, outcome realization) and player-side (responsiveness, timing, reflection, engagement) variables, noting perplexity/BLEU are insufficient. — [arXiv 2601.18785](https://www.arxiv.org/pdf/2601.18785). Generative Agents used TrueSkill rankings from 100 raters on believability interviews. — [arXiv 2304.03442](https://arxiv.org/html/2304.03442v2). Unbounded used CLIP/DreamSim/DINO consistency metrics and GPT-4 pairwise judging. — [arXiv 2410.18975](https://arxiv.org/html/2410.18975v1). MovieAgent used subject/background consistency, motion smoothness, dynamic degree and two expert raters. — [arXiv 2503.07314](https://arxiv.org/html/2503.07314v1)
- Player agency findings: Elsewise (authoring tool) user study — participants rated the agency of their LLM-made stories as moderate (median 4), one noting open-ended chat "can feel free without giving real plot progression"; opaque models hide behaviour from authors so they cannot deliberately shape agency; bundled-storyline visualization proposed as the fix. — [arXiv 2601.15295](https://arxiv.org/pdf/2601.15295). Player-Driven Emergence: emergent nodes came mostly from exploration-oriented players. — [arXiv 2404.17027](https://arxiv.org/pdf/2404.17027)
- Failure-mode catalogue with sources: fact conflicts dominant (40-68%) and early termination — [NCP-Bench](https://arxiv.org/html/2608.08160); memory enforcement overriding player intent (HiAgent 13%→38% player-input conflicts) — same; item/enemy drift and context-fill degradation, prompt brittleness, content-filter interruptions — [ChatRPG](https://arxiv.org/html/2502.19519v2); environment-driven dynamics mispredicted — [Wang 2024](https://arxiv.org/html/2406.06485v1); hallucination drift as agents explore out-of-distribution states — [TWM survey](https://arxiv.org/pdf/2606.09032); continuity errors, ungrounded objects, trait over-indexing, auto-completing objectives, consequence-free choices, near-guaranteed success, slow responses — [Hidden Door review](https://ianbicking.org/blog/2025/08/hidden-door-design-review-llm-driven-game); repetition ("10,000 bowls of oatmeal"), slot-machine effect, inability to judge reversals/foreshadowing inside a chain — [Showrunner](https://fablestudio.github.io/showrunner-agents/); "LLMs tend to repeat patterns without human intervention" — [MSR](https://www.microsoft.com/en-us/research/project/emergence/); SKT's strict gating produced "forced conversational reveals" usability friction — [arXiv 2609.23043](https://arxiv.org/abs/2609.23043); sycophantic face-preservation +45 pp vs humans — [ELEPHANT](https://www.alphaxiv.org/abs/2505.13995.md); latency makes the loop "feel like waiting for a remote service" — [AI Native Games](https://arxiv.org/pdf/2607.00527).

### Inferences
- Every positive controlled result comes with N≤12 or expert-rater panels of 2-7; effect sizes are large but statistical power is low; the field has no shared long-session benchmark for *interactive* play with real players, so an internal NCP-Bench-style auditor (fact ledger + commitments + player-input fidelity) is the most defensible automated metric to adopt.
- The recurring pairing of "structure fixes consistency" with "structure hurts responsiveness/agency" (HiAgent, SKT, Hidden Door menus) means evaluation must track both axes simultaneously; optimizing coherence alone will produce a railroaded game.

### Gaps
- No user study directly compares an LLM agent-based GM to a human GM on the same scenario beyond NCP-Bench's single-environment human pilot.
- No longitudinal (multi-session, days-long) player study of an LLM GM was found.
